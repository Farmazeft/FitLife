# FitLife
Проект предназначен для расчета показателей ИМТ и нормы потребления воды с учетом параметров пользователя.
Разрабатывается в рамках 1 спринта курса python-разработчик.

# Требования к среде
Программы:
    VSCode 1.143.1
Пакеты:
    Python 3.14.3
    виртуальное окружение, заполненное из requirements.txt

# Как запустить
1. Активировать виртуальное окружение
    'source venv/Scripts/activate'
2. Запустить программу
    'python fit_life.py'
